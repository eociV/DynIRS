# DynIRS (dynamic per-box IR soft-label weights) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the constant IR soft-label weight ω = 0.3 of IRS-YOLO26n with per-box weights computed from a YOLO26l IR teacher (variants T, TL, plus shuffled control S), and run the experiment matrix of the spec on five nano YOLO models.

**Architecture:** An offline script (`src/omega.py`) runs the IR teacher once, stores per-box signals (teacher confidence `c`, RGB visibility `v`), and writes per-box weight files for each variant. The training code (`src/lowlight.py`) reads those files, carries ω through Ultralytics augmentation by encoding it into the class value, and decodes it into the existing per-box loss weight `box_w`. Queue files generated by a script drive training on the local GPU (Windows) and on Kaggle / Colab T4 sessions.

**Tech Stack:** Python 3.11, PyTorch (CUDA 12.8 build for the RTX 5060 Ti), Ultralytics 8.4.173, NumPy, SciPy, OpenCV, pycocotools, pytest; Kaggle CLI.

**Spec:** `docs/superpowers/specs/2026-11-23-dynamic-ir-soft-weights-design.md`

## Global Constraints

- `ultralytics==8.4.173` exactly (pinned in `requirements.txt` and `src/job_main.py`).
- Python 3.11 virtual environment at `.venv/` for local work.
- Student protocol: 40 epochs, imgsz 640, batch 32, splits under `splits/`, soft-label-only (`tgd_lambda: 0`, no `distill_model`).
- Configurations: B (RGB only), M (RGB + IR train images mixed, no teacher), C (`ir_soft: 0.3`), T, TL, S. B, M and S on YOLO26n only; v8n / 11n / v10n / 12n run C, T, TL.
- Every configuration, baselines included, uses identical training settings and environment; val and test are RGB.
- Weights: floor 0.05, ceiling 1, train-set mean 0.3 ± 0.001 after clipping, γ = 1, teacher match IoU ≥ 0.5, class-agnostic.
- ω-T raw = `c`; ω-TL raw = `c · (1 − v)`; S = ω-T values permuted across all IR-only train boxes with seed 0.
- Teacher: YOLO26l from `yolo26l.pt`, IR frames, imgsz 640, batch 16, 50 epochs (30 if bench × 50 > 12 h), local GPU only.
- Hardware: all YOLO26n runs and the teacher on the local RTX 5060 Ti; all v8n / 11n / v10n / 12n runs on T4.
- Seeds 0, 1, 2 for every model and configuration (54 student runs).
- T4 runs are split across team accounts; queue files are per (model, seed). If T4 capacity is short, move whole models to the local GPU after the teacher; dropping 12n then v10n is the last resort.
- Gate after YOLO26n seed 0: if neither T nor TL beats C on overall or night RGB AP50:95, stop and ask the user.
- Training efficiency (spec §4b), identical for every configuration: `load_ir: false` for soft-label runs, pre-warmed `.npy` disk cache with `cache: "disk"`, `deterministic: False`, up to 2 lanes per GPU host (Kaggle T4 ×2: one run per GPU). Validation every epoch and `best.pt` stay.
- Commit after every task. Never push without the user asking.

```python
def encode_wsoft(cls, w):
    """Encode class and per-box weight into one float32 class value that survives augmentation."""
    q = np.clip(np.rint(np.asarray(w, np.float64) * WSOFT_LEVELS), 0, WSOFT_LEVELS).astype(np.int64)
    return (WSOFT_OFFSET + N_CLS * q + np.asarray(cls, np.int64)).astype(np.float32)


def decode_wsoft(enc):
    k = (enc - WSOFT_OFFSET).round().long()
    return (k % N_CLS).to(enc.dtype), (k // N_CLS).to(torch.float32) / WSOFT_LEVELS


def split_box_weights(cls, ir_soft=None, pseudo=None):
    """Flat class tensor (possibly offset-encoded) -> (plain classes, per-box loss weights)."""
    wsoft = cls >= WSOFT_OFFSET
    ps = (cls >= PSEUDO_OFFSET) & ~wsoft
    soft = (cls >= SOFT_OFFSET) & ~wsoft
    w = torch.where(ps, float(pseudo or 1.0), torch.where(soft, float(ir_soft or 1.0), 1.0)).to(torch.float32)
    out = torch.where(ps, cls - PSEUDO_OFFSET, torch.where(soft, cls - SOFT_OFFSET, cls))
    if bool(wsoft.any()):
        c, q = decode_wsoft(cls[wsoft])
        out = out.clone()
        out[wsoft] = c
        w[wsoft] = q.to(w.device)
    return out, w
```

```python
"""Per-box weights for IR-only soft labels (DynIRS).

Signals per IR-only train box i (computed once, offline):
  c_i  confidence of the IR teacher: highest score of a teacher prediction on the IR frame with
       IoU >= MATCH_IOU to box i, class-agnostic; 0 if none.
  v_i  RGB visibility: mean BT.601 luminance of the RGB pixels inside box i, scaled to [0, 1].
Variants: T = c, TL = c * (1 - v)**gamma, S = T values permuted across boxes (seed 0).
Every variant is scaled by one constant s and clipped to [FLOOR, CEIL] so that the train-set mean
equals TARGET (the constant weight of the original recipe).
"""

from __future__ import annotations

import json
import sys

import numpy as np

from dv_pairs import iou_matrix  # noqa: E402

W, H = 640, 512
FLOOR, CEIL, TARGET = 0.05, 1.0, 0.3
MATCH_IOU = 0.5
VARIANTS = ("T", "TL", "S")


def xywhn_to_xyxy(a):
    a = np.asarray(a, float).reshape(-1, 4)
    x, y, w, h = a[:, 0] * W, a[:, 1] * H, a[:, 2] * W, a[:, 3] * H
    return np.stack([x - w / 2, y - h / 2, x + w / 2, y + h / 2], 1)


def teacher_conf(boxes, pred_boxes, pred_scores, iou_thr=MATCH_IOU):
    boxes = np.asarray(boxes, float).reshape(-1, 4)
    out = np.zeros(len(boxes))
    if len(boxes) == 0 or len(pred_boxes) == 0:
        return out
    m = iou_matrix(boxes, np.asarray(pred_boxes, float).reshape(-1, 4))
    s = np.where(m >= iou_thr, np.asarray(pred_scores, float)[None], 0.0)
    return s.max(1)


def box_luminance(img_rgb, boxes):
    h, w = img_rgb.shape[:2]
    y = (0.299 * img_rgb[..., 0] + 0.587 * img_rgb[..., 1] + 0.114 * img_rgb[..., 2]) / 255.0
    out = []
    for x1, y1, x2, y2 in np.asarray(boxes, float).reshape(-1, 4):
        c1 = int(np.clip(np.floor(x1), 0, w - 1))
        r1 = int(np.clip(np.floor(y1), 0, h - 1))
        c2 = max(int(np.clip(np.ceil(x2), 0, w)), c1 + 1)
        r2 = max(int(np.clip(np.ceil(y2), 0, h)), r1 + 1)
        out.append(float(y[r1:r2, c1:c2].mean()))
    return np.array(out)


def raw_weights(c, v, variant, gamma=1.0):
    c, v = np.asarray(c, float), np.asarray(v, float)
    if variant in ("T", "S"):
        return c.copy()
    if variant == "TL":
        return c * (1.0 - v) ** gamma
    raise ValueError(f"unknown variant {variant}")


def mean_match(raw, target=TARGET, lo=FLOOR, hi=CEIL, tol=1e-4):
    raw = np.asarray(raw, float)
    f = lambda s: np.clip(raw * s, lo, hi).mean()  # noqa: E731
    if np.clip(raw * 1e12, lo, hi).mean() < target:
        raise ValueError("target mean unreachable: too few boxes with a positive raw weight")
    a, b = 0.0, 1.0
    while f(b) < target:
        b *= 2
    for _ in range(200):
        s = (a + b) / 2
        if f(s) < target:
            a = s
        else:
            b = s
        if abs(f(b) - target) <= tol:
            break
    return np.clip(raw * b, lo, hi), b


def shuffle(w, seed=0):
    return np.random.default_rng(seed).permutation(np.asarray(w, float))
```

```python
def load_ironly(proc):
    out = {}
    for f in sorted((Path(proc) / "ironly_cls" / "train").glob("*.txt")):
        a = np.loadtxt(f, ndmin=2, dtype=np.float64) if f.stat().st_size else np.zeros((0, 5))
        out[f.stem] = a.reshape(-1, 5)
    return out


def compute_signals(proc, predict_fn, batch=32):
    import cv2

    proc = Path(proc)
    boxes = load_ironly(proc)
    sig = {k: [] for k in boxes}
    ids = [k for k in boxes if len(boxes[k])]
    for i in range(0, len(ids), batch):
        chunk = ids[i:i + batch]
        preds = predict_fn([str(proc / "ir" / "train" / "images" / f"{k}.jpg") for k in chunk])
        for k, (pb, ps) in zip(chunk, preds):
            xy = xywhn_to_xyxy(boxes[k][:, 1:5])
            rgb = cv2.imread(str(proc / "rgb" / "train" / "images" / f"{k}.jpg"), cv2.IMREAD_COLOR)[..., ::-1]
            c = teacher_conf(xy, pb, ps)
            v = box_luminance(rgb, xy)
            sig[k] = [[round(float(a), 5), round(float(b), 5)] for a, b in zip(c, v)]
        print(f"signals {min(i + batch, len(ids))}/{len(ids)}", flush=True)
    return sig


def build_weights(signals, variant, seed=0):
    ids = sorted(signals)
    n = [len(signals[k]) for k in ids]
    arr = np.array([x for k in ids for x in signals[k]], float).reshape(-1, 2)
    raw = raw_weights(arr[:, 0], arr[:, 1], variant)
    w, s = mean_match(raw)
    if variant == "S":
        w = shuffle(w, seed)
    out, j = {}, 0
    for k, m in zip(ids, n):
        out[k] = w[j:j + m]
        j += m
    hist, edges = np.histogram(w, bins=20, range=(0, 1))
    stats = {"variant": variant, "n_boxes": int(len(w)), "scale": float(s), "mean": float(w.mean()),
             "frac_floor": float(np.mean(w <= FLOOR + 1e-9)), "frac_ceil": float(np.mean(w >= CEIL - 1e-9)),
             "frac_c_zero": float(np.mean(arr[:, 0] == 0)), "hist": hist.tolist(),
             "edges": edges.round(2).tolist()}
    return out, stats


def write_weights(proc, variant, boxes, weights):
    out = Path(proc) / "ironly_w" / variant / "train"
    out.mkdir(parents=True, exist_ok=True)
    for k in sorted(boxes):
        b, w = boxes[k], weights.get(k, np.zeros(0))
        if len(b) != len(w):
            raise ValueError(f"{k}: {len(b)} boxes but {len(w)} weights")
        (out / f"{k}.txt").write_text("".join(
            f"{int(r[0])} {r[1]:.6f} {r[2]:.6f} {r[3]:.6f} {r[4]:.6f} {x:.4f}\n" for r, x in zip(b, w)))
    return out


def _ultralytics_predictor(teacher, imgsz, batch):
    from ultralytics import YOLO

    m = YOLO(str(teacher))

    def fn(paths):
        res = m.predict(source=paths, imgsz=imgsz, conf=0.001, max_det=300, half=True, verbose=False, batch=batch)
        return [(r.boxes.xyxy.cpu().numpy(), r.boxes.conf.cpu().numpy()) for r in res]

    return fn


def main(argv=None):
    ap = argparse.ArgumentParser()
    sub = ap.add_subparsers(dest="cmd", required=True)
    s = sub.add_parser("signals")
    s.add_argument("--proc", required=True)
    s.add_argument("--teacher", required=True)
    s.add_argument("--imgsz", type=int, default=640)
    s.add_argument("--batch", type=int, default=32)
    w = sub.add_parser("weights")
    w.add_argument("--proc", required=True)
    w.add_argument("--variant", choices=VARIANTS, required=True)
    a = ap.parse_args(argv)
    proc = Path(a.proc)
    if a.cmd == "signals":
        sig = compute_signals(proc, _ultralytics_predictor(a.teacher, a.imgsz, a.batch), a.batch)
        (proc / "stats" / "omega_signals.json").write_text(json.dumps(sig))
        flat = np.array([x for v in sig.values() for x in v]).reshape(-1, 2)
        print(json.dumps({"n_boxes": len(flat), "c_mean": float(flat[:, 0].mean()),
                          "frac_c_zero": float(np.mean(flat[:, 0] == 0)), "v_mean": float(flat[:, 1].mean())}))
    else:
        sig = json.loads((proc / "stats" / "omega_signals.json").read_text())
        weights, stats = build_weights(sig, a.variant)
        write_weights(proc, a.variant, load_ironly(proc), weights)
        (proc / "stats" / f"omega_{a.variant}.json").write_text(json.dumps(stats, indent=1))
        print(json.dumps({k: stats[k] for k in ("variant", "n_boxes", "scale", "mean", "frac_floor", "frac_ceil")}))


if __name__ == "__main__":
    main()
```

```python
"""Pre-write Ultralytics disk-cache files (<image>.npy = the decoded BGR image) atomically.

  python scripts/warm_cache.py --splits train val --mods rgb [ir]

Ultralytics 8.4 loads an existing <image>.npy instead of decoding the JPEG, whatever the cache mode.
Writing the files once, before training, lets parallel runs share them without write races.
"""
import argparse
import os
from concurrent.futures import ProcessPoolExecutor
from pathlib import Path

import cv2
import numpy as np

ROOT = Path(__file__).resolve().parents[1]


def cache_one(path):
    f = Path(path)
    npy = f.with_suffix(".npy")
    if npy.exists() and npy.stat().st_mtime >= f.stat().st_mtime:
        return 0
    tmp = npy.with_name(npy.stem + ".tmp.npy")
    np.save(tmp, cv2.imread(str(f), cv2.IMREAD_COLOR), allow_pickle=False)
    os.replace(tmp, npy)
    return 1


def warm(files, workers):
    with ProcessPoolExecutor(workers) as ex:
        return sum(ex.map(cache_one, files, chunksize=64))


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("--splits", nargs="+", default=["train", "val"])
    ap.add_argument("--mods", nargs="+", default=["rgb"])
    ap.add_argument("--workers", type=int, default=os.cpu_count())
    a = ap.parse_args(argv)
    proc = Path(os.environ.get("DV_DATA", ROOT / "data" / "dronevehicle")) / "proc"
    files = [str(f) for m in a.mods for s in a.splits for f in sorted((proc / m / s / "images").glob("*.jpg"))]
    print("cached", warm(files, a.workers), "of", len(files), flush=True)


if __name__ == "__main__":
    main()
```

```python
"""Seed-paired t intervals and Holm correction for DynIRS."""
import numpy as np
from scipy import stats


def paired_t(diffs):
    d = np.asarray(diffs, float)
    n, m, sd = len(d), d.mean(), d.std(ddof=1)
    half = stats.t.ppf(0.975, n - 1) * sd / np.sqrt(n)
    p = float(stats.ttest_1samp(d, 0).pvalue)
    return {"mean": float(m), "sd": float(sd), "n": n, "t_ci": [float(m - half), float(m + half)], "p": p}


def holm(pvals):
    p = np.asarray(pvals, float)
    order = np.argsort(p)
    adj = np.empty_like(p)
    run = 0.0
    for rank, i in enumerate(order):
        run = max(run, (len(p) - rank) * p[i])
        adj[i] = min(run, 1.0)
    return adj.tolist()
```

```python
def ironly_recall(preds, thr=0.25):
    by = {}
    for p in preds:
        if p["score"] >= thr:
            by.setdefault(p["image_id"], []).append(p["bbox"])
    hit = tot = 0
    for f in sorted((D / "ironly_cls" / "test").glob("*.txt")):
        if not f.stat().st_size:
            continue
        g = xywhn_to_xyxy(np.loadtxt(f, ndmin=2)[:, 1:5])
        tot += len(g)
        if f.stem in by:
            hit += int((iou_matrix(g, np.array(by[f.stem])).max(1) >= 0.5).sum())
    return 100.0 * hit / max(tot, 1)


def band_weights(ids, band):
    return np.ones(len(ids)) if band == "all" else ev.subset_weights(ids, (MAN / f"test_{band}.txt").read_text().split())

        r[f"{lab}_{band}"] = 100 * m.ap(band_weights(m.ids, band))
```

```python
"""Build Kaggle dataset folders for DynIRS (upload with the Kaggle CLI).

  python scripts/pack_kaggle.py data  --user KAGGLE_USER    -> kaggle_ds/dynirs-dv
  python scripts/pack_kaggle.py omega --user KAGGLE_USER    -> kaggle_ds/dynirs-omega
  python scripts/pack_kaggle.py code  --user KAGGLE_USER    -> kaggle_ds/dynirs-code
  kaggle datasets create -p kaggle_ds/<slug> --dir-mode zip          (first time)
  kaggle datasets version -p kaggle_ds/<slug> -m "update" --dir-mode zip
"""
import argparse
import json
import os
import shutil
from pathlib import Path

ROOT = Path(__file__).resolve().parents[1]


def _meta(out, slug, user):
    (out / "dataset-metadata.json").write_text(json.dumps(
        {"title": slug, "id": f"{user}/{slug}", "licenses": [{"name": "other"}]}, indent=1))


def _fresh(out, slug):
    d = Path(out) / slug
    shutil.rmtree(d, ignore_errors=True)
    d.mkdir(parents=True)
    return d


def pack_data(proc, out, slug, user):
    d = _fresh(out, slug)
    dst = d / "proc"
    dst.mkdir()
    for sub in ("rgb", "ir", "ironly", "ironly_cls", "stats"):
        shutil.copytree(Path(proc) / sub, dst / sub, ignore=shutil.ignore_patterns("*.npy", "*.cache"))
    for f in Path(proc).glob(".ready_*"):
        shutil.copy2(f, dst / f.name)
    _meta(d, slug, user)
    return d


def pack_omega(proc, out, slug, user):
    d = _fresh(out, slug)
    shutil.copytree(Path(proc) / "ironly_w", d / "ironly_w")
    (d / "stats").mkdir()
    for f in (Path(proc) / "stats").glob("omega_*.json"):
        if f.name != "omega_signals.json":
            shutil.copy2(f, d / "stats" / f.name)
    _meta(d, slug, user)
    return d


def pack_code(root, out, slug, user):
    d = _fresh(out, slug)
    for sub in ("src", "scripts", "configs", "splits"):
        shutil.copytree(Path(root) / sub, d / sub, ignore=shutil.ignore_patterns("__pycache__"))
    shutil.copy2(Path(root) / "requirements.txt", d / "requirements.txt")
    _meta(d, slug, user)
    return d


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("what", choices=["data", "omega", "code"])
    ap.add_argument("--user", required=True)
    ap.add_argument("--out", default=str(ROOT / "kaggle_ds"))
    a = ap.parse_args(argv)
    proc = Path(os.environ.get("DV_DATA", ROOT / "data" / "dronevehicle")) / "proc"
    fn = {"data": lambda: pack_data(proc, a.out, "dynirs-dv", a.user),
          "omega": lambda: pack_omega(proc, a.out, "dynirs-omega", a.user),
          "code": lambda: pack_code(ROOT, a.out, "dynirs-code", a.user)}[a.what]
    print(fn())


if __name__ == "__main__":
    main()
```

```python
"""Run one DynIRS queue inside a Kaggle or Colab session.

  python scripts/kaggle_session.py --queue configs/queues/dyn/t4_v8n_s0_c.json \
      --data-in /kaggle/input/dynirs-dv --omega-in /kaggle/input/dynirs-omega \
      --prev-out /kaggle/input/<previous-session-output> --work /kaggle/working

Copies the prepared data to fast local disk (/tmp/dv), adds the ω files, restores runs/ from a
previous session's output (so chunked training resumes from last.pt), and runs the queue from a copy
of the code in <work>/DynIRS. Results stay in <work>/DynIRS/runs for download / the next session.
"""
import argparse
import os
import shutil
import subprocess
import sys
from pathlib import Path


def main(argv=None):
    ap = argparse.ArgumentParser()
    ap.add_argument("--queue", required=True)
    ap.add_argument("--data-in", required=True)
    ap.add_argument("--omega-in")
    ap.add_argument("--prev-out")
    ap.add_argument("--work", required=True)
    ap.add_argument("--code-in", default=str(Path(__file__).resolve().parents[1]))
    ap.add_argument("--only", nargs="*")
    ap.add_argument("--lanes", type=int, default=2)
    ap.add_argument("--gpus", default="0,1")
    ap.add_argument("--mods", nargs="+", default=["rgb"], help="modalities to pre-cache (add ir for M or teacher)")
    a = ap.parse_args(argv)
    work = Path(a.work)
    repo = work / "DynIRS"
    if not repo.exists():
        shutil.copytree(a.code_in, repo, ignore=shutil.ignore_patterns("runs", "data", "kaggle_ds", ".git"))
    dv = Path("/tmp/dv")
    if not (dv / "proc").exists():
        shutil.copytree(Path(a.data_in) / "proc", dv / "proc")
    if a.omega_in:
        shutil.copytree(Path(a.omega_in) / "ironly_w", dv / "proc" / "ironly_w", dirs_exist_ok=True)
    if a.prev_out:
        prev = next(Path(a.prev_out).rglob("runs/remote"), None)
        if prev:
            shutil.copytree(prev, repo / "runs" / "remote", dirs_exist_ok=True)
            print("restored", prev, flush=True)
    subprocess.run([sys.executable, "-m", "pip", "install", "-q", "-r", str(repo / "requirements.txt")], check=True)
    env = dict(os.environ, DV_DATA=str(dv))
    subprocess.run([sys.executable, "scripts/warm_cache.py", "--splits", "train", "val", "--mods", *a.mods],
                   cwd=repo, env=env, check=True)
    cmd = [sys.executable, "scripts/run_lanes.py", a.queue, "--lanes", str(a.lanes), "--gpus", a.gpus]
    cmd += ["--only", *a.only] if a.only else []
    return subprocess.run(cmd, cwd=repo, env=env).returncode


if __name__ == "__main__":
    sys.exit(main())
```
Note: `run_queue.py` skips nothing on its own; a finished job is retrained if rerun. Before each session, pass `--only` with the jobs not yet finished (a job is finished when `runs/remote/<name>/ws/out/<name>/preds_test.json` exists).
